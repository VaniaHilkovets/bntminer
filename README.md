# BNT Miner

GPU-майнер BNT / Blocknet для NVIDIA RTX 30, 40 и 50 серий. Бинарник — для Linux x86_64. Скачать: [последний релиз](https://github.com/VaniaHilkovets/bntminer/releases/latest).

## Требования

- Linux x86_64: Ubuntu 22.04 / 24.04 или система с glibc 2.34 или новее.
- Драйвер NVIDIA **580.82.07 или новее**. Проверено на RTX 5090 с драйвером 595.91.07.
- Минимум 2.25 GiB свободной VRAM.
- Системные библиотеки `libstdc++`, `libgcc_s`, `libc` и `libm`.

CUDA runtime 13.0 включён в бинарник. Устанавливать CUDA Toolkit для запуска не нужно. Включены нативные ядра для Ampere, Ada и Blackwell: sm_80, sm_86, sm_89, sm_120. Используется быстрый алгоритм без резервного медленного режима. Перед запуском проверяется полный PoW-хеш. Если результат неверен, майнер останавливается.

В v1.0.1 исправлена генерация начальных блоков Argon2 на Blackwell. RTX 5090 проверена аппаратно; v1.0.0 проходила проверку на RTX 4090. Совместимость с каждой моделью RTX 30/40/50 без аппаратных испытаний обещать нельзя.

## Скачать и запустить

```bash
curl -fL https://github.com/VaniaHilkovets/bntminer/releases/latest/download/bntminer-linux-x86_64 -o bntminer-linux-x86_64
chmod +x bntminer-linux-x86_64
./bntminer-linux-x86_64 --pool-url stratum+tcp://bntpool.com:3333 --address YOUR_BLOCKNET_ADDRESS
```

Замените `YOUR_BLOCKNET_ADDRESS` своим публичным адресом выплат Blocknet. Приватные ключи и seed-фраза не нужны.

Дополнительные параметры:

```bash
./bntminer-linux-x86_64 --pool-url stratum+tcp://bntpool.com:3333 --address YOUR_BLOCKNET_ADDRESS --worker rig01 --devices 0,1
./bntminer-linux-x86_64 --list-devices
./bntminer-linux-x86_64 --bench --bench-seconds 30
./bntminer-linux-x86_64 --help
```

По умолчанию используются все обнаруженные GPU. Остановка — `Ctrl+C`. Для отключения цвета: `--no-color`.

## Комиссия разработчика

**5% вычислительной работы GPU** направляется на фиксированный dev-кошелёк. Из каждых 20 назначенных полных PoW-вычислений одно относится к dev-заданию, 19 — к пользовательскому. Первый nonce относится к dev. Шары отправляются по мере нахождения; первая принятая шара может принадлежать любой роли.

Это исправляет проблему v1.0.0: доля в 5% от количества шар занижала доход разработчика, когда dev-пул выдавал более лёгкие шары. В v1.0.1 сложность dev-шар не уменьшает выделенную dev-долю GPU. Майнер также запрашивает у dev-пула сложность пользовательской сессии, однако окончательный target задаёт пул и он может проигнорировать запрос. Отбрасывать лёгкие валидные dev-шары невыгодно: пул всё равно засчитает их со своей сложностью.

Принятая работа учитывается по сложности подтверждённых шар. При нормальном учёте пула, взвешенном по сложности, ожидаемая доля dev-дохода соответствует доле вычислений. На коротком интервале она колеблется из-за случайности, обновлений заданий, отклонений и задержек пула; ровно 5% выплаты в каждый момент не гарантируется. При разных пользовательском и dev-пулах правила выплат также могут различаться.

Фиксированные реквизиты:

- Dev-пул: `stratum+tcp://bntpool.com:3333`
- Dev-адрес: `6LGk2RRtEbRansBvbDQi5S8JsrhkrGu8qeQAcQj1kvYjMLhFeP9srXSbpSwTsaatRF8ktEcSvjwWs2nxYM8gRzSc1ig56`

Параметров отключения комиссии или замены её реквизитов нет. Комиссия указана при старте и в статистике. Когда один из пулов недоступен, майнинг ждёт восстановления подключения.

## Память и скорость

PoW: Argon2id v19, 2 GiB, t=1, p=1. Массив Argon2 остаётся в VRAM. Число параллельных nonce определяется по свободной видеопамяти. CPU обслуживает сеть и небольшие служебные буферы; перенос массива PoW в системную RAM не используется.

Офлайн-бенчмарк считает полные хеши, а не accepted shares. Логи показывают GPU, подключение, хешрейт, принятые/отклонённые шары и dev fee. Скорость зависит от карты, доступной VRAM, частот и частоты смены заданий пула. Результаты проверки включены в архив релиза.

## Целостность и лицензии

Бинарник очищен от отладочных символов и проверяет свою подпись Ed25519. Простое изменение файла приводит к отказу запуска. Подпись обеспечивает проверку целостности, но не делает реверс-инжиниринг невозможным.

Для проверки загрузки скачайте `SHA256SUMS.txt` из того же релиза:

```bash
sha256sum -c SHA256SUMS.txt --ignore-missing
```

Архив содержит бинарник, инструкцию, результаты проверки и лицензии зависимостей. Части CUDA-кода и протокол пула основаны на [Seine](https://github.com/zpalmtree/seine), BSD 3-Clause. Уведомление: `LICENSE-THIRD-PARTY.txt`. Лицензии Rust-зависимостей и NVIDIA CUDA runtime находятся в `licenses/`.
